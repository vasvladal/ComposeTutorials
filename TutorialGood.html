Установка и настройка окружения

1.1. Установка Android Studio

Скачайте и установите последнюю версию Android Studio (2025.1 или новее) с официального сайта:

https://developer.android.com/studio

1.2. Установка JDK 25

Данный проект использует Java/Kotlin Toolchain версии 25. Убедитесь, что у вас установлен JDK 25:

  • Перейдите в File → Settings → Build, Execution, Deployment → Build Tools → Gradle
  • В поле Gradle JDK выберите JDK 25 (или позвольте Android Studio скачать его автоматически)
Начиная с AGP 9.0+, Android Studio использует встроенную поддержку Kotlin и не требует отдельного плагина kotlin-android. Kotlin компилируется через Android Gradle Plugin напрямую.

1.3. Требования к окружению

Создание нового проекта в Android Studio

2.1. Создание проекта

  1. Откройте Android Studio → File → New → New Project
  2. Выберите шаблон Empty Activity (Compose)
  3. Нажмите Next

2.2. Настройка проекта

ПараметрЗначение
NameComposeTutorials
Package namecom.example.composetutorials
Save locationЛюбая удобная директория
LanguageKotlin
Minimum SDKAPI 24
Build configuration languageKotlin DSL (build.gradle.kts)

Нажмите Finish и дождитесь завершения синхронизации.

2.3. Создание модуля Tutorial1-1Basics

После создания базового проекта необходимо создать отдельный модуль:

  1. File → New → New Module
  2. Выберите Android Library или Phone & Tablet Module
  3. Module name: Tutorial1-1Basics
  4. Package name: com.example.composetutorials
  5. Minimum SDK: API 24
  6. Language: Kotlin
В данном проекте модуль Tutorial1-1Basics является основным и содержит всё приложение. Корневой проект служит для общей конфигурации.

Настройка settings.gradle.kts

Откройте settings.gradle.kts в корне проекта и замените содержимое:

settings.gradle.kts pluginManagement { repositories { gradlePluginPortal() google() mavenCentral() } } plugins { id("org.gradle.toolchains.foojay-resolver-convention") version "1.0.0" } dependencyResolutionManagement { repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS) repositories { google() mavenCentral() maven { url = uri("https://jitpack.io") } } } rootProject.name = "ComposeTutorials" include(":Tutorial1-1Basics")

Пояснения:

  • pluginManagement — определяет, откуда загружать Gradle-плагины
  • foojay-resolver-convention — плагин для автоматического скачивания JDK по toolchain URL
  • dependencyResolutionManagement — централизованное управление репозиториями зависимостей
  • FAIL_ON_PROJECT_REPOS — запрещает модулям объявлять собственные репозитории
  • include(":Tutorial1-1Basics") — подключает наш модуль к сборке

Корневой build.gradle.kts

Замените содержимое корневого build.gradle.kts:

build.gradle.kts (корневой) // Корневой build.gradle.kts plugins { alias(libs.plugins.android.application) apply false alias(libs.plugins.kotlin.parcelize) apply false alias(libs.plugins.compose) apply false }

Пояснения:

  • apply false — плагины объявляются, но не применяются к корневому проекту. Они будут применены в модулях.
  • alias(libs.plugins...) — типобезопасный доступ к плагинам из Version Catalog.
В AGP 9.0+ НЕ нужен плагин kotlin-android. Kotlin поддерживается встроенно через AGP.

Настройка MainActivity.kt

Откройте Tutorial1-1Basics/src/main/java/com/example/composetutorials/MainActivity.kt и замените содержимое:

MainActivity.kt package com.example.composetutorials import android.os.Bundle import androidx.activity.ComponentActivity import androidx.activity.compose.setContent import androidx.compose.foundation.layout.fillMaxSize import androidx.compose.material3.MaterialTheme import androidx.compose.material3.Surface import androidx.compose.ui.Modifier class MainActivity : ComponentActivity() { override fun onCreate(savedInstanceState: Bundle?) { super.onCreate(savedInstanceState) setContent { MaterialTheme { Surface( modifier = Modifier.fillMaxSize(), color = MaterialTheme.colorScheme.background ) { // ✅ Вызов основного экрана туториала Tutorial1_1Screen() } } } } }

Пояснения:

  • ComponentActivity — базовая Activity для Compose-приложений (не требует AppCompat)
  • setContent { } — точка входа в Compose-иерархию
  • MaterialTheme — обёртка с материалом Material 3 (тема, типографика, цвета)
  • Surface — корневой контейнер с фоном из темы
  • Tutorial1_1Screen() — наш экран туториала из шага 11
Убедитесь, что вызывается именно Tutorial1_1Screen() (а не TutorialContent()). Функция Tutorial1_1Screen() помечена аннотацией @Preview и является публичной точкой входа, тогда как TutorialContent() — приватная.

Синхронизация и запуск проекта

13.1. Синхронизация Gradle

  1. Нажмите File → Sync Project with Gradle Files (или иконку слона 🐘 на панели инструментов)
  2. Дождитесь завершения загрузки зависимостей (при первом запуске может занять несколько минут)
  3. Проверьте вкладку Build внизу на наличие ошибок

13.2. Создание эмулятора

  1. Откройте Tools → Device Manager
  2. Нажмите Create Virtual Device
  3. Выберите устройство (например, Pixel 7)
  4. Выберите системный образ с API 35+
  5. Завершите создание

13.3. Запуск приложения

  1. Выберите модуль Tutorial1-1Basics в конфигурации запуска (вверху рядом с кнопкой Run)
  2. Выберите эмулятор или подключённое устройство
  3. Нажмите ▶ Run (или Shift + F10)
После успешной сборки и запуска вы увидите приложение с прокручиваемым списком примеров: Row → Column → Box → Spacer → Weight and Spacer. Каждый раздел содержит визуальные примеры с пояснительным текстом.

13.4. Использование Preview

Откройте файл Tutorial1_1ColumnRowBoxScreen.kt и переключитесь на вкладку Split или Design в правом верхнем углу редактора. Вы увидите превью для:

  • Светлой темы
  • Тёмной темы
  • Планшета (PIXEL_C)
Превью обновляются автоматически при изменении кода. Если превью не обновилось, нажмите иконку Build & Refresh на панели превью.

14.3. Частые проблемы и решения

ПроблемаРешение
Ошибка «Plugin [id: com.android.application] was not found» Убедитесь, что в pluginManagement указаны репозитории google() и gradlePluginPortal()
Ошибка «Could not resolve androidx.compose:compose-bom» Проверьте, что google() указан в dependencyResolutionManagement
Превью не отображается Нажмите Build & Refresh на панели превью. Убедитесь, что функция отмечена @Preview и не имеет параметров
«Unresolved reference: kotlin» в build.gradle.kts В AGP 9+ не нужно применять плагин kotlin-android — Kotlin встроен
Ошибка компиляции с JDK Проверьте, что в gradle-daemon-jvm.properties указана toolchainVersion=25
Приложение падает при запуске Проверьте AndroidManifest.xml: Activity должна быть exported="true" с intent-filter MAIN/LAUNCHER
