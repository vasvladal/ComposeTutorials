🚀 Руководство разработчика

Jetpack Compose Tutorials — от создания проекта до запуска приложения

📅 Версия: 2026 🎯 Kotlin 📱 Android Studio 🎨 Jetpack Compose

Введение

Это полное руководство по созданию учебного Android-проекта на Jetpack Compose. Мы последовательно:

  1. Проанализируем ошибки сборки — поймём, почему Gradle не мог найти зависимости
  2. Изучим учебный Compose-код — разберём основы Layout
  3. Создадим рабочий проект — пошагово соберём всё с нуля
💡 Для кого это руководство? Для начинающих Android-разработчиков, которые хотят понять современный подход к разработке приложений с Jetpack Compose, Kotlin DSL и Version Catalog.

Часть 1: Анализ ошибок сборки

При попытке собрать проект Jetpack-Compose-Tutorials мы столкнулись с 8 параллельными ошибками. Все они сводились к одной причине:

// Ключевая ошибка из логов Gradle
Could not find com.google.accompanist:accompanist-systemuicontroller:0.37.3.
Searched in the following locations:
  - https://dl.google.com/dl/android/maven2/...
  - https://repo.maven.apache.org/maven2/...
  - https://jitpack.io/...

🔍 Основные проблемы

1. Несуществующая версия библиотеки

Версия 0.37.3 библиотеки accompanist-systemuicontroller никогда не выпускалась. Библиотека была объявлена deprecated, и её последний релиз — 0.36.0.

2. Устаревший ID плагина

// Устаревший ID
com.github.ben-manes.versions

// Актуальный ID
io.github.ben-manes.versions

3. Deprecated-флаги в gradle.properties

AGP 9.0+ изменил значения по умолчанию для многих флагов. Явное задание старых значений вызывало предупреждения:

  • android.usesSdkInManifest.disallowed=false
  • android.sdk.defaultTargetSdkToCompileSdkIfUnset=false
  • android.enableAppCompileTimeRClass=false
  • android.builtInKotlin=false
  • android.newDsl=false
  • android.r8.optimizedResourceShrinking=false
  • android.defaults.buildfeatures.resvalues=true
  • android.nonFinalResIds=false

Исправления, применённые в проекте

✅ Три ключевых исправления

Все три проблемы были решены до создания проекта, чтобы он собрался с первого запуска.

Исправление 1: Версия accompanist-systemuicontroller

В файле libs.versions.toml добавлена отдельная версия:

[versions]
accompanist = "0.37.3"           # для остальных библиотек
accompanistSystemUi = "0.36.0"   # исправлено!

[libraries]
accompanist-systemuicontroller = {
    module = "com.google.accompanist:accompanist-systemuicontroller",
    version.ref = "accompanistSystemUi"
}

Исправление 2: Опечатка в коде

В файле Tutorial2_10_3BottomDrawer.kt была опечатка:

// Было (с пробелом — не скомпилируется):
scope.launch { d rawerState.close() }

// Стало:
scope.launch { drawerState.close() }

Исправление 3: Очистка gradle.properties

Удалены устаревшие флаги, добавлен рекомендуемый для производительности:

# Рекомендуется для больших проектов
android.dependency.excludeLibraryComponentsFromConstraints=true

Часть 2: Обзор Compose-кода

Исходный код представляет собой интерактивный учебник по фундаментальным концепциям Jetpack Compose. Рассмотрим его структуру.

🎯 Назначение файла

Файл служит самодостаточной шпаргалкой для разработчиков, начинающих изучать декларативный UI в Android. В нём наглядно демонстрируются:

  • Row — горизонтальное расположение элементов
  • Column — вертикальное расположение элементов
  • Box — наложение элементов по оси Z (как Stack)
  • Modifier — изменение свойств компонентов
  • Spacer и weight — управление пространством

Разбор ключевых компонентов

📦 Row, Column, Box

КомпонентНазначениеГлавный параметр
RowДети располагаались горизонтальноhorizontalArrangement
ColumnДети располагаются вертикальноverticalArrangement
BoxДети накладываются друг на другаAlignment

⚠️ Ключевой момент: Порядок модификаторов

Порядок применения модификаторов имеет значение!

Это одно из важнейших правил Compose, которое наглядно показано в примере ColumnsAndRowPaddingsExample.

// Вариант A: .background() применяется ПЕРВЫМ
// → padding создаёт внутренний отступ для текста
val modifierA = Modifier
    .background(Color.Yellow)
    .padding(15.dp)

// Вариант B: .padding() применяется ПЕРВЫМ
// → padding работает как margin (внешний отступ)
val modifierB = Modifier
    .padding(10.dp)
    .background(Color.Cyan)
    .padding(end = 15.dp)

📏 Weight и Spacer

Modifier.weight() позволяет распределять оставшееся пространство пропорционально весам:

Row(modifier = Modifier.fillMaxWidth()) {
    Text("Вес 2", modifier = Modifier.weight(2f))
    Spacer(modifier = Modifier.weight(1f))  // промежуток
    Text("Вес 3", modifier = Modifier.weight(3f))
    Spacer(modifier = Modifier.weight(1f))  // промежуток
    Text("Вес 4", modifier = Modifier.weight(4f))
}

Часть 3: Создание проекта с нуля

1

Создание нового проекта

  1. Откройте Android Studio → New Project
  2. Выберите шаблон Empty Activity → Next
  3. Заполните поля:
    • Name: ComposeTutorials
    • Package name: com.smarttoolfactory.tutorial1_1basics
    • Language: Kotlin
    • Minimum SDK: API 24: Android 7.0 (Nougat)
    • Build configuration language: Kotlin DSL
  4. Нажмите Finish
Переименуйте модуль app!

Правый клик по папке app → Refactor → Rename → Tutorial1-1Basics

Корневые файлы проекта

2

Настройка settings.gradle.kts (корень)

Переключите вид на Project (а не Android) и замените содержимое файла:

pluginManagement {
    repositories {
        gradlePluginPortal()
        google()
        mavenCentral()
    }
}

plugins {
    id("org.gradle.toolchains.foojay-resolver-convention") version "1.0.0"
}

dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven { url = uri("https://jitpack.io") }
    }
}

rootProject.name = "ComposeTutorials"
include(":Tutorial1-1Basics")
3

Настройка build.gradle.kts (корень проекта)

Здесь объявляются плагины, которые используются в модулях:

plugins {
    alias(libs.plugins.gradle.versions)
    alias(libs.plugins.version.catalog.update)
    alias(libs.plugins.android.application) apply false
    alias(libs.plugins.kotlin.android) apply false
    alias(libs.plugins.kotlin.parcelize) apply false
    alias(libs.plugins.compose) apply false
    alias(libs.plugins.jetbrains.kotlin.serialization) apply false
    alias(libs.plugins.ksp) apply false
    alias(libs.plugins.hilt) apply false
}

Настройка Version Catalog

5

Файл gradle/libs.versions.toml

Это современный способ управления зависимостями. Обратите внимание на отдельную версию для systemuicontroller:

[versions]
accompanist = "0.37.3"
accompanistSystemUi = "0.36.0"  # 🎯 КЛЮЧЕВОЕ ИСПРАВЛЕНИЕ
androidGradlePlugin = "8.5.2"
androidx-activity-compose = "1.9.3"
androidx-compose-bom = "2024.10.00"
androidx-corektx = "1.15.0"
compileSdk = "35"
kotlin = "2.0.21"
minSdk = "24"
targetSdk = "35"
# ... остальные версии

[libraries]
accompanist-systemuicontroller = {
    module = "com.google.accompanist:accompanist-systemuicontroller",
    version.ref = "accompanistSystemUi"  # 🎯 используем особую версию
}
# ... остальные библиотеки
💡 Почему Version Catalog?

Позволяет управлять всеми версиями из одного места, поддерживает автодополнение в IDE и обеспечивает типобезопасность.

Настройка модуля приложения

6

Файл Tutorial1-1Basics/build.gradle.kts

plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.kotlin.android)
    alias(libs.plugins.kotlin.parcelize)
    alias(libs.plugins.compose)
}

android {
    namespace = "com.smarttoolfactory.tutorial1_1basics"
    compileSdk = libs.versions.compileSdk.get().toInt()

    defaultConfig {
        applicationId = "com.smarttoolfactory.tutorial1_1basics"
        minSdk = libs.versions.minSdk.get().toInt()
        targetSdk = libs.versions.targetSdk.get().toInt()
        versionCode = 1
        versionName = "1.0"
    }

    compileOptions {
        sourceCompatibility = JavaVersion.VERSION_17
        targetCompatibility = JavaVersion.VERSION_17
    }

    kotlinOptions {
        jvmTarget = "17"
    }

    buildFeatures {
        compose = true
    }
}

dependencies {
    val composeBom = platform(libs.androidx.compose.bom)
    implementation(composeBom)

    implementation(libs.kotlin.stdlib)
    implementation(libs.androidx.core.ktx)
    implementation(libs.androidx.activity.compose)
    implementation(libs.androidx.compose.ui)
    implementation(libs.androidx.compose.foundation)
    implementation(libs.androidx.compose.material3)

Синхронизация и запуск

10

Синхронизация Gradle

  1. В верхнем правом углу появится сообщение "Gradle files have changed"
  2. Нажмите Sync Now
  3. Дождитесь зеленой галочки BUILD SUCCESSFUL
Если Sync Failed

Проверьте, что в libs.versions.toml для accompanist-systemuicontroller используется версия 0.36.0, а не 0.37.3.

11

Запуск приложения

  1. Выберите эмулятор или подключите устройство
  2. Нажмите зеленую кнопку Run (или Shift+F10)
  3. Дождитесь установки APK
🎉 Ожидаемый результат

Откроется экран с нижней шторкой (BottomDrawer), которую можно:

  • Открывать кнопкой "Click to open"
  • Вытягивать свайпом вверх
  • Закрывать кнопкой внутри шторки

Чекбокс позволяет включать/отключать жесты свайпа.
